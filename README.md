# InduTradex Website

Static responsive B2B/export website for InduTradex.

## Upload
Upload the contents of this folder to your cPanel `public_html` directory.

## Before publishing
1. Business email is configured as `connect@indutradex.com`.
2. Phone/WhatsApp is configured as `+91 99730 60050`.
3. Replace placeholder contact information.
4. Replace image URLs with licensed product/farm photography if required.
5. Add real certifications, grades, MOQ, export documents and product specifications only when supported by actual business documentation.

## Form
The quote form currently opens the visitor's email client using `mailto:`. For production lead capture, connect it to a PHP/API/email service.

## Main sections
Home, Products, About, B2B Solutions, Export, Private Label, Quality, Process, Request a Quote, Contact.
