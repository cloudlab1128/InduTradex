# InduTradex Image Editing Guide

Product images are kept in this folder so they can be replaced without changing the page layout.

## Product images

- `makhana.jpg` — Premium Makhana
- `roasted-makhana.jpg` — Roasted & Flavoured Makhana
- `turmeric.jpg` — Premium Turmeric
- `dry-fruits.jpg` — Premium Dry Fruits

## How to replace an image

1. Open this folder on GitHub.
2. Upload a new image using the exact filename above.
3. If GitHub asks whether to replace the existing file, confirm the replacement.
4. GitHub Pages will redeploy automatically.

The website CSS already points to these filenames, so no HTML editing is needed when replacing a product photo.
